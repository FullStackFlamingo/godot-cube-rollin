# Cube Rolling

A little project to explore a few things:

- rolling a cube on a grid (no physics)
- 'painting' the grid tiles with the cube faces
- Godot component composition style ala hooks/composable
- Event up / data down communication between nodes, just like frontend web frameworks!

# Grid Movement 
Pre-calculated enter/exit nodes allow for easy movement between ramp tiles, in any way you care to place them.
Classic A-Star movement based on these tiles entrances/exits.
